API Gateway Documentation

Welcome to the API Gateway Documentation. This page provides information on how to access and use our API documentation.

Swagger Documentation

We use Swagger/OpenAPI for documenting our API endpoints. You can access the documentation in several ways:

Local Development

URL: http://localhost:3000/api-docs

This is available when running the API locally with npm run dev

Netlify Dev (Local)

URL: http://localhost:8888/.netlify/functions/swagger

This is available when running Netlify Dev with netlify dev

Production

URL: https://your-site-name.netlify.app/.netlify/functions/swagger

This is the production Swagger documentation

API Base URLs

Depending on your environment, use one of the following base URLs for API requests:

  • Local Development: http://localhost:3000
  • Netlify Dev: http://localhost:8888/.netlify/functions
  • Production: https://your-site-name.netlify.app/.netlify/functions

Raw OpenAPI Specification

If you need the raw OpenAPI specification in JSON format:

  • Local: http://localhost:3000/swagger.json
  • Production: https://your-site-name.netlify.app/.netlify/functions/swagger
